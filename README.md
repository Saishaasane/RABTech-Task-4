# Responsive Design Tokens & Mobile-First CSS Architecture
A modern responsive dashboard designed using a mobile-first CSS architecture. The project demonstrates the use of design tokens, responsive layouts, modern UI effects, and light/dark theme switching.

## Features

- Mobile-first responsive design
- CSS design tokens using `:root`
- Custom colors, typography, spacing, and border-radius variables
- Responsive CSS Grid layout
- Flexbox
- Light/Dark theme switching
- Glassmorphism effects
- Soft shadows and hover transitions
- Responsive activity chart
- Progress indicators
- No horizontal scrolling on mobile devices
- Theme preference saved using Local Storage

## Responsive Breakpoints

- 320px – Small Mobile
- 768px – Tablet
- 1024px – Desktop
- 1440px – Large Desktop

## Technologies Used

- HTML5
- CSS3
- JavaScript
- CSS Custom Properties
- CSS Grid
- Flexbox
- Responsive Web Design
- Local Storage
